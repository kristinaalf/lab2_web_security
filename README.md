# Лабораторная работа: Веб-уязвимости

## Часть 1: Уязвимое приложение
Приложение на Flask. Запуск: `python app.py`.
Уязвимости:
1. SQL Injection (A03:2021) — в форме логина.
2. Cross-Site Scripting (A03:2021) — при выводе комментариев.
3. Broken Access Control (A01:2021) — страница /admin.

## Часть 2: Эксплуатация
Скрипт `exploit.py` автоматически проверяет все три уязвимости.

## Часть 3: Патчинг
Файл `fix.diff` содержит изменения, которые исправляют уязвимости.
